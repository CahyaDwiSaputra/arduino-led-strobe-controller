# 💡 Arduino Uno Non-Linear LED Strobe Pattern Controller

Proyek kontrol aktuator digital sederhana berbasis **Arduino Uno** yang menghasilkan pola kedipan strobo non-linear menggunakan teknik manipulasi interval timing mikroskopik dan milidetik.

---

## 🚀 Fitur & Pola Sinyal
- Mengontrol pin output digital 13 (Built-in LED).
- Mengatur urutan waktu kedipan bergantian (*asymmetrical timing waveform*) untuk simulasi lampu blitz atau strobo sinyal darurat:
  - ON 250 ms $\rightarrow$ OFF 1000 ms $\rightarrow$ ON 50 ms $\rightarrow$ OFF 500 ms.

---

## 🛠️ Hardware Requirements
- **Board**: Arduino Uno / Nano / Mega
- **Pin Output**: Pin Digital 13 (LED Built-in)
